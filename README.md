# Indian_Kids_Screentime_ml
Indian Kids Screen Time Prediction using Machine Learning
Project Overview
This project focuses on analyzing and predicting the **average daily screen time of children in India** using Machine Learning.
The project uses information such as age, gender, primary device used, whether the recommended screen-time limit was exceeded, educational-to-recreational screen-time ratio, reported health impacts, and urban/rural classification.
The main objective is to build regression models that can predict a child's **average daily screen time in hours** based on these factors.
Problem Statement
Excessive screen time among children has become an important concern due to its possible association with sleep problems, eye strain, anxiety, and other health-related impacts.
Understanding the factors associated with children's screen usage can help in identifying patterns and developing data-driven insights.
This project therefore aims to answer:
> **Can Machine Learning models predict the average daily screen time of children based on demographic, device usage, educational, health, and geographical factors?**
The major objectives of this project are:
- Analyze children's screen-time data.
- Clean and preprocess the dataset.
- Identify relevant features for prediction.
- Handle missing and categorical data.
- Apply appropriate data preprocessing techniques.
- Build multiple regression models.
- Compare model performance using evaluation metrics.
- Predict average daily screen time for new inputs.
- Develop an interactive prediction interface using `ipywidgets`.
**Target Variable**
The target variable is:
Avg_Daily_Screen_Time_hr`
The model attempts to predict the average number of hours a child spends on screens per day.
